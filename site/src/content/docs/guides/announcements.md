---
title: Post announcements
description: Publish, edit, expire, and remove session announcements.
---

Session admins and jury members manage announcements. Roles combine, so either role is enough.
Every current member of the session reads the active announcements.

The **Announcements** list is above the issue workspace on every screen.
Select a title to show its details and images.

## Publish

1. Select **New announcement**.
2. Enter a **Title** (up to 160 characters) and **Details** (up to 10,000 characters of plain text).
3. Optional: set **Expires (optional)** to a future time.
4. Select **Publish**.

Publication is immediate. The announcement shows your name and the publication time.

## Add images

Open a published announcement and use **Add an image**.

- Formats: JPEG, PNG, and WebP.
- Up to 4 images, 10 MB each. The issue image limits do not apply.
- If an upload fails, select **Retry upload**. The text stays published.

Managers can remove any image of an announcement.

## Edit

Open the announcement, select **Edit**, change it, and select **Save changes**.
The original publisher and time stay. The latest editor and time also show.

If another manager changed the announcement first, Minsky shows the latest version.
Select **Keep my draft** or **Load latest text**, then save again.

## Expire or remove

- At its expiry time, an announcement leaves the readers' list.
  To show it again, edit it and clear or extend the expiry.
- To remove it now, select **Remove**, then **Confirm removal**. Removal is final.

Managers still see expired and removed announcements with an **Active**, **Expired**, or **Removed** label.
Archived events stay readable and reject every announcement change.
