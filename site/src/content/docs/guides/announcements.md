---
title: Post announcements
description: Publish, edit, expire, and remove contest announcements.
---

Contest admins and jury members manage announcements. Roles combine, so either role is enough.
Every current member of the contest reads the active announcements.

The **Announcements** list is above the issue workspace on every screen.
Select a title to show its details and images.

## Show more or hide the list

The list shows the two newest announcements. Select **Show N more** to see the rest, where N is the number that are hidden.
Select **Show fewer** to return to two.

Select **Hide** to close the list. A one-line bar with the number of announcements and **Show** stays.
Hiding the list does not delete anything. Open announcements and unsent drafts stay as they were.
When someone publishes a new announcement, the list shows again.
Your browser remembers the choice for your account and this contest.

## Publish an announcement

1. Select **New announcement**.
2. Enter a **Title** of up to 160 characters and **Details** of up to 10,000 characters of plain text.
3. To end the announcement at a set time, enter a future time in **Expires (optional)**.
4. Select **Publish**.

Minsky publishes the announcement at once. The announcement shows your name and the publication time.

## Add images

Open a published announcement and use **Add an image**.

- The formats are JPEG, PNG, and WebP.
- An announcement holds up to 4 images of 10 MB each. The issue image limits do not apply.
- If an upload fails, select **Retry upload**. The text stays published.

Managers can remove any image of an announcement. **Remove** asks you to confirm first. Select **Remove image** to delete the file. Select **Keep image** to cancel. Minsky cannot restore a deleted image.

## Edit an announcement

Open the announcement, select **Edit**, change it, and select **Save changes**.
The original publisher and time stay. The latest editor and time also show.

If another manager changed the announcement first, Minsky shows the latest version.
Select **Keep my draft** or **Load latest text**, then save again.

## Expire or remove an announcement

- At its expiry time, an announcement leaves the readers' list. To show it again, edit it and clear or extend the expiry.
- To remove an announcement now, select **Remove**, then **Remove announcement**. The announcement leaves the list for everyone, managers included. Minsky keeps the record for the contest log. To stop, select **Keep announcement**.

Managers still see expired announcements with an **Expired** label.
If another manager removes an announcement while you edit it, your draft stays on screen, but you cannot save it.
