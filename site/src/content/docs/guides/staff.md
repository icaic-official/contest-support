## Find the report

Choose **Issues** in the sidebar.
Use the status filter to narrow the queue.
Team search accepts a team name or location and tolerates small spelling differences.
Select a suggestion explicitly.
Typing a name alone does not select the team.

The same team choice applies to **Report for team**.
Clear the choice to restore the full queue.
Select a team again if you edit the search text.
Search matches only teams in the current session.

## Claim and investigate

1. Open an unassigned issue.
2. Claim the issue.
3. Contact the team and investigate the problem.
4. Record the relevant details in the issue.

Minsky records the first assignment separately from the submission time.
The issue timer uses saved timestamps, so a browser refresh does not reset it.
If another staff member claims first, check the updated owner before you act.

## Choose the audience

Use **Audience** before you send a reply.
A public reply is visible to the contestant team.
An internal note is visible only to authorized staff.
Do not put internal investigation details in a public reply.

### Attach an image

All staff members can upload JPEG, PNG, and WebP images while the event is active.
Open the image controls in the issue details.
Choose **Staff only** or **Visible to the team** before upload.
The default is **Staff only**.
The visibility choice stays fixed after upload.

Only the uploader can remove an image, and only while the event is active.
Resolved issues still accept authorized uploads.
Archived events allow reading but prevent uploads and removal.

If an upload fails, use its retry control.
Use **Cancel upload** before you select a different file or audience.
If removal fails, use **Retry removal** until cleanup completes.
See [image limits](/guides/administration/#set-image-limits) if a file is rejected.

## Hand off to a specialist

Request a specialist handoff when the issue needs that capability.
You remain the owner until a specialist accepts.
The timer continues during the handoff.
The accepting specialist becomes the owner.
The activity history records both actions and their actors.

## Resolve and reopen

Record a resolution summary when the issue is resolved.
Choose a supplied summary or write a custom one.
Resolution stops the timer.

Reopening retains the prior owner and all resolution summaries.
The timer resumes accumulated unresolved time.
Existing awards and external application status remain unchanged.

## Report for a team

Volunteers and specialists can use **Report for team**.
Select the correct team before submission.
This remains available when contestant intake is closed, provided the event is active.
Jury-only membership does not grant this control.
