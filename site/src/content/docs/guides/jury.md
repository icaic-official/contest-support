title: Review issues and record time awards
description: Record an award decision and track its separate application to an external contest clock.
---

## Review the issue

Jury-only members use **Award review**, which shows resolved issues.
Team search can narrow that list.
Members with combined support and jury roles also receive the support controls.
Jury-only access does not permit claiming, resolving, or reopening an issue.
Ask support staff to reopen a resolved issue if it needs further discussion.

Read the issue description, elapsed unresolved time, resolution history, and staff notes before you decide.
The first assignment time shows when a staff member first claimed the issue.
It is separate from the elapsed unresolved time.

## Record the decision

1. Open the resolved issue.
2. Enter the award in whole minutes.
3. Enter the public explanation for the team.
4. Record the award.

Zero minutes is a valid decision.
Use the value justified by your competition's rules.
The current app supports one award per issue.
Repeated submissions cannot create duplicate awards.

## Record external application

An authorized staff member separately confirms when the award was applied to the external contest system.
Complete that external action before confirming it in Minsky.
Minsky stores the confirmation but does not change another system's clock.
Contestants can see both the decision and its application status.

If the issue is reopened, its award and external application status remain.
Reopening does not authorize a second award for the same issue.
