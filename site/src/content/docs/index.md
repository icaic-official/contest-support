## One shared record, from report to resolution

Minsky helps contest teams report technical problems.
Volunteers and specialists handle those reports in a shared queue.
Jury members record time awards, and staff record when someone applies them to the external contest clock.

| Your task | Start here |
| --- | --- |
| Report a problem and follow its progress | [Contestant guide](/guides/contestants/) |
| Claim, investigate, or hand off an issue | [Staff guide](/guides/staff/) |
| Review a resolved issue and record an award | [Jury guide](/guides/jury/) |
| Create accounts and manage access | [Administration guide](/guides/administration/) |
| Run Minsky for another competition | [Installation options](/operators/installation/) |
| Change these pages and publish them | [Documentation workflow](/contributing/documentation/) |

## Know which version you are using

These guides describe the source repository, including merged issue images and team search.
A running installation can use an older revision.
See [feature status](/reference/status/) before you rely on a feature.

[Open the development app](https://minsky-dev.icaic-minsky.workers.dev).
Use only accounts and data approved for development.
Ask your organizer for your competition's address.

:::note[Development stage]
Live-contest readiness and capacity for 800 simultaneous users remain unverified.
Minsky currently requires a working network connection.
Independent installation packaging is pending review in T0007.
:::
